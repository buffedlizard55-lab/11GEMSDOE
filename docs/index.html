PRIMARY FILE AUDIT VERIFIED

GEMSDOE1 and 5G reused the same file

Published primary artifacts from GEMSDOE and 5GEMSDOE compare byte-for-byte: SHA-256 7f00890a…, 570,890 bytes, identical pixels. This explains the reported 0.1563 match. 8GEMSDOE also shows 0.1563 with a different TIFF and different prediction pixels.
