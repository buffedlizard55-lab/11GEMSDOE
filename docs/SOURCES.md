## Citation discipline

- A conceptual fault mechanism is a candidate explanation, never a verified discovery until data and validation support it.
- Distinguish an official statement from our inference. E.g. the official task says new expert-labeled faults are absent from the current public fault database; it does **not** say every high-scoring predictor outside the catalogue is a geological fault.
- Do not infer exact raster band positions from prose. Inspect metadata of the actual TIFF.
- Record source snapshot date, file checksum, license, and geographic coverage when using external layers. Public availability alone does not establish compatibility or contest eligibility.
